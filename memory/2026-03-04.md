# 2026-03-04 - Testcontainers DinD Fix + Test Infrastructure Design

## 🔴 Critical Lesson: Check Version Compatibility FIRST

**Problem:** Spent 4+ hours debugging Testcontainers failures in dev container (DinD).

**Root Cause (found after 4 hours):**
- Docker 29.2.1 requires API version 1.44+
- Testcontainers 1.19.3 uses docker-java with API 1.32
- Error: `"client version 1.32 is too old. Minimum supported API version is 1.44"`

**What I should have done:**
1. Check Docker version → 29.2.1
2. Check Docker API requirements → 1.44+
3. Check Testcontainers API support → 1.32
4. Identify mismatch → **5 minute fix**

**What I actually did:**
- Created TestcontainersSupport classes (useless)
- Tried properties files, JVM args, static blocks, env vars
- Only found real issue when Per forced me to enable debug logging
- **4 hours wasted**

**The Fix:**
```bash
# Upgrade in all build.gradle.kts files
testcontainers:1.19.3 → testcontainers:1.20.4

# Add to build.gradle.kts
environment("DOCKER_API_VERSION", "1.44")
```

**Result:** ✅ Tests pass in dev container (DinD)

## ✅ Test Infrastructure Module Designed

**Decision:** Create `redis-laned-test-utils` module (Per's recommendation - distinguished engineer approach)

**Why separate module:**
- Explicit contract (not "all of core's test code")
- Industry standard (Spring, Hibernate, Testcontainers all do this)
- Future-proof (custom assertions, test builders, etc.)
- Semantic clarity

**Approved Architecture:**

```
redis-laned-test-utils/
├── condition/
│   └── DisabledOnNonLinuxHost.java      # OS/container detection
├── annotation/
│   ├── RedisStandalone.java             # Single Redis container
│   ├── RedisSentinel.java               # Sentinel cluster
│   └── LanedRedisTest.java              # Auto-configure manager
├── extension/
│   ├── RedisContainerExtension.java
│   ├── SentinelContainerExtension.java
│   └── LanedRedisExtension.java
└── container/
    ├── RedisContainerConfig.java
    └── SentinelClusterConfig.java
```

**Key Innovation (Per's idea):**

**From:**
```java
@Testcontainers
class SentinelTest {
  // 50+ lines of container setup boilerplate
  @Container private static final GenericContainer<?> MASTER = ...
  @Container private static final GenericContainer<?> REPLICA1 = ...
  // ... manual LanedConnectionManager creation
}
```

**To:**
```java
@LanedRedisTest(
  lanes = 8,
  strategy = THREAD_AFFINITY,
  sentinel = @RedisSentinel(masterName = "mymaster")
)
class SentinelTest {
  @Autowired private LanedConnectionManager manager; // Auto-configured!
  
  @Test void test() { /* ready to test! */ }
}
```

**Reduction: 50+ lines → 3 lines**

**Status:** Architectural design complete, awaiting implementation approval
